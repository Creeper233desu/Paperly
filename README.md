# 纸间

面向移动设备的 Vue 3 / uni-app 本地写作应用。直接在 HBuilderX 打开项目根目录运行或云打包。正文按纯文本段落保存，界面为 app-vue WebView。

## 运行与打包

1. 在 HBuilderX 中打开本目录，运行到 Android 平板或模拟器。
2. 通过“发行 → 原生 App 云打包”生成 APK。`manifest.json` 已有 AppID，如更换 DCloud 账号，请在 HBuilderX 中确认 AppID 归属。

## 功能与结构

- `pages/library`：书架、统计、设置共用的主页面；三个内容面板平行滑动，底部导航固定。书架可选取 DOCX 或 PDF，预览识别出的目录，并修改书名、作者、简介后导入。首次进入时连接固定的公共数据目录。
- `components/StatisticsPanel.vue`：近半年每日净字数热力图、每日书籍与篇章来源。只在进入统计面板时从账本读取独立快照，隐藏时不刷新显示；再次进入会更新跨日日期和最右侧的最新热力图。
- `components/BookPanel.vue`：可折叠的章节与正文目录、接续上次写作、文本筛选、PDF 与图片导出。书架使用 `BookTransition.vue` 在当前页面展开详情，按实际布局位置衔接卡片、封面、标题和作者；关闭时从当前滚动位置收回卡片。详情独立滚动，书架滚动位置保留。过渡期间底部导航置于动效上方，按钮可用；详情完全展开后隐藏导航。
- `src/utils/book-morph.js` / `book-spring.js`：书本动效在 renderjs 视图层执行，开始或布局变化时读取几何，动画帧只更新位移、缩放和透明度。固定布局配合反向变换保持正文排版尺寸；弹簧保存当前位置与速度，返回和再次打开可在途中反向。切换主导航立即释放点击并同步淡出，进入编辑器或后台时暂停，返回后继续；销毁时取消待执行帧。减少动态效果模式直接落定。逻辑层只收发命令和阶段事件，不逐帧跨层更新。
- `pages/reader`：应用内只读阅读视图，直接使用可编辑书籍的章节和段落；与编辑器共用字号滑块、字号范围和字体，支持可上锁的双指缩放。
- `pages/export-image`：书本详情入口先选正文，再通过只读文字的长按选区、一个滑条的双滑块或左右位置输入框确定连续文本；编辑器长按菜单的“导出图片”直接带入已选文字。浅色或深色卡片可选书本信息，也可从本机选择、更换或移除背景图片；图片等比居中铺满，透明度可在 0%（不透明）至 100%（完全透明）之间调整，正文不受影响。实时预览直接显示导出画布生成的临时 PNG，文字排版、卡片比例、背景裁切、透明度与最终图片完全一致；快速调整时合并更新并丢弃过时结果。点击生成后确认该图片，同时复制到固定数据目录；仅点击“保存到相册”才写入相册，也可通过系统文件打开入口分享。
- `pages/editor`：连续文本编辑、回车后自然段首行缩进、实时字数统计、全书篇章侧栏、段落聚焦、标点补全、撤销重做、前后查找与替换、沉浸模式、动画光标，以及长按后的复制、粘贴、剪切、全选菜单。侧栏切换正文只更新编辑内容，不重建整个页面；工具栏操作保留页面滚动位置，查找将光标移到匹配末尾。聚焦与动画光标分别同步到 renderjs；动画在主动移动光标或换行时播放，普通输入与删除不触发。`DocumentInput` 先显示正文并保留可输入的备用控件，待 renderjs 成功接管后启用逐段编辑；正文更新带篇章版本号，避免旧篇章的延迟更新覆盖新篇章。缩进由段落样式绘制，不写入正文；旧版自动生成的全角空格在打开正文时清理。
- `pages/settings`：外观、字体、编辑体验、AI 助手和应用设置分为五个入口，具体选项在居中弹窗中设置。外观提供浅色、深色及五种强调色；应用设置包含语言、立即备份、删除数据和版本信息。动画光标可选经典竖线或 Neovim 方块样式，设置中可查看实时运动预览。自定义颜色在应用内色板中选取。已导入字体显示独立预览。AI 可保存多组 OpenAI、Anthropic、Kimi、DeepSeek 配置，模型列表从所选服务商实时获取，支持的模型可设置思考强度。
- `components`：底部导航、连续正文输入、应用内操作菜单、确认对话框；`RollingNumber.vue` 共用按位滚动的数字显示，`src/composables/use-panel-entrance.js` 控制入场动效及离页清理，不重建面板。
- `src/store`：书库、设置、每日统计、AI 多配置及按书籍保存的会话记录。编辑器关闭时同一进程内的 AI 请求继续运行，重新进入可见已收到的回复。
- `src/services`：Android PDF、PNG 绘制、封面持久化、字体与 DOCX 导入，以及各模型服务商的模型列表和流式聊天。`data-directory.js` 自动发现 `Documents/PaperWriter`、复制资源并维护可恢复的快照；`reload-data.js` 在恢复后刷新各个响应式 store。AI 只接收当前书本的限长上下文，较早对话压缩为摘要；同一轮的增删提案按顺序规划，接受一项后重新定位剩余提案，再经现有保存入口记录净字数。
- `src/utils/text.js`：可单独测试的编辑与替换逻辑。

书库的存储键为 `paperwriter.library.v1`，层级为 `books[] → chapters[] → articles[] → paragraphs[]`。每本书的 `lastEdited` 保存最近写作的篇章与光标位置。旧书缺少作者、封面或写作位置字段时仍可正常读取。设置存于 `paperwriter.preferences.v1`，统计存于 `paperwriter.statistics.v1`。每日统计按本地日期保存所有书籍的正文净字数变化：导入 DOCX/PDF 时计入正文总字数，后续编辑计入差值，删除正文、章节或书籍计入负数，并保留书籍与篇章来源。标题、空白和图片标记不计入。整本文档的增减批量保存一次；旧版 PDF 转换仅记录转换前后的正文差值，避免重复计数。安装本版本前的历史写作和导入不会补算，已有书籍从本版本起的编辑与删除正常计入。

Android 应用使用公共 `Documents/PaperWriter/` 作为固定数据目录，启动时自动检查。首次安装需授予文件访问权限；Android 11 及以上会进入系统“管理所有文件”授权页。应用将书库、统计、偏好、AI 配置与会话的快照写入该目录，封面、插图、自定义字体同步复制到 `assets/`，导出的 PDF 和 PNG 写入 `exports/`。`assets/.nomedia` 和 `exports/.nomedia` 阻止封面、正文插图和生成的 PNG 备份被系统相册自动收录，升级时也会请求刷新已有媒体索引；用户主动保存到相册的副本保存在相册目录中。写作时仍使用本机快速存储，并在更改后同步公共快照。卸载重装后，再次授予系统权限即可自动恢复最近完成的快照及资源.

AI 配置含明文 API Key、模型和可编辑的系统提示词，保存在本机应用设置并同步到固定数据目录；对话时会将当前书本正文片段和选中文字发送给所选服务商。编辑器底栏的 ✦ 打开侧栏，可在侧栏切换配置与模型、创建会话或展开全屏；长按选择正文后可从菜单把选中文字带入对话。回答及服务商实际返回的思考内容按流式事件显示；若 Android 一次性交付网络数据，界面仍逐步显示已收到的内容，不生成虚构的思考过程。助手的 `insert_text` 与 `delete_text` 只生成待确认修改；接受前会按唯一原文位置重新定位，无法安全定位时保留提案并提示冲突。其他工具调用不执行。会话存于 `paperwriter.assistantSessions.v1`，配置存于 `paperwriter.aiProfiles.v1`；应用进程被终止时正在进行的请求不能继续。

助手输入区分别选择模型和思考强度，并显示下次请求的**预估**上下文 token 用量。获取模型列表及所选模型详情时，保留 API 返回的上下文窗口和思考能力；`src/services/model-capabilities.js` 统一处理不同服务商的返回格式，不根据模型名称猜测能力。API 提供的窗口优先使用，缺失时可按服务商说明手动填写，并为每个模型分别保存。API 未提供思考选项时会明确提示手动选择，默认不指定强度。实际 token 用量仍由服务商分词计算，界面数值仅供写作时参考。供应商图标使用可跟踪的 `static/providers/` 资源，OpenAI 与 Anthropic 随应用主题切换。

助手输入区还可切换修改权限。默认“修改需确认”会展示差异，等待作者接受；选择“完全访问”前会显示风险说明。开启后，工具修改会自动写入当前书本，包括删除篇章。应用前仍会核对目标和原文，若写作过程中内容发生变化，会尝试安全地重新定位；无法定位的修改不会自动应用。这个偏好保存在本机，发出消息时的权限模式适用于该次请求。

编辑器可在光标处插入本地图片，插入前可预览、更换或取消。图片独立成段，文字缩放不改变图片比例；PNG 文字卡片跳过图片，PDF 导出按正文顺序绘制图片。书本详情的“阅读”只保留目录和正文。所有书籍都支持 12–36 px 字号滑块和带锁的双指缩放；阅读与编辑使用相同字号偏好。

书架和书本详情的书籍编辑窗口均支持“移除封面”，点击保存后恢复默认文字封面。

封面、正文插图和 PNG 自定义背景统一使用应用内裁切界面，不依赖原生裁切插件。选择本机原图后，可拖动选区移动位置、拖动四角调整范围，再确认保存；封面锁定书架使用的 7:10 比例，插图和背景支持自由框选、原比例、1:1、4:3、3:4 和 16:9。裁切结果保存为 PNG，保留透明通道，并限制输出尺寸以降低移动设备内存占用；取消不会替换已选图片。`npm run test:image-crop` 和 `npm run test:image-export` 分别验证裁切流程与 PNG 背景导出。

## 日期显示

日期显示可在“设置 → 应用设置 → 日期显示”选择中文（默认）、原有英文或日语格式，并预览当天的显示效果。例如：`2026年9月30日，周三`、`Wed Sep 30 2026`、`2026年9月30日（水）`。切换应用语言时会自动选择对应格式，之后仍可单独更改；偏好重启后保留，书架、统计、备份时间和 PDF 导出日期使用同一格式。

## DOCX 导入

Android 上通过系统文档选择器导入 `.docx`，最大 16 MB。应用读取 DOCX 的文字及文档属性：书名默认取文档属性的标题，其次取 Word 的 Title 样式，最后取文件名；作者和简介优先取文档属性，导入前都可编辑。Word 一级标题划分章节、二级标题划分篇名；普通文本中“第 X 章”和“第 X 节”也可识别。没有标题的段落会放入默认“正文”章节。仅导入文字与段落，不导入图片或复杂排版；成功保存后，导入正文计入当日净字数，之后的编辑与删除也按实际增减计入。

## 字体

随应用内置 **思源宋体 Noto Serif SC** 和 **霞鹜文楷 Lite**，在离线环境下也可切换。字体及许可分别位于 `static/fonts/`，均按 SIL Open Font License 1.1 随附许可文本。两款字体总计约 39 MB，会增加 APK 体积。

Android 上可从系统文件选择器导入 TTF/OTF。应用通过 Android 文件描述符读取所选字体，再复制到 `_doc/fonts/`，核对复制后的文件大小，加载并记录路径；重启后仍可选用。字体设置弹窗会按实际字体显示每款自定义字体的中文预览。单个导入文件限制 25 MB。该功能依赖 Android Native.js 和 `uni.loadFontFace`，仍需在云打包后的 APK 上检查不同设备的文件选择器与字体渲染。

## PDF

PDF 导出使用 Android `PdfDocument`，支持可选目录和作者信息，先生成于 `_doc/`，随后复制到 `Documents/PaperWriter/exports/`。修复了对原生 Canvas 直接调用 `drawText` 的兼容问题，改用 `plus.android.invoke`。书本阅读页使用应用内段落视图，不依赖 PDF 页渲染。PDF 生成及文件复制依赖 Android 原生运行环境，不能通过 Node 单元测试完全验证。

## PDF 导入

书架的“导入文稿”支持 DOCX 和 PDF，均生成普通可编辑书籍。PDF 在本地使用 PDF.js 提取文字层，识别“第 X 章 / 节”标题，合并排版断行，过滤重复页眉和页码；没有章标题时归入“正文”。书名、作者和简介先从元数据填充，再由用户修改。成功保存后，提取的正文计入当日净字数，后续修改和删除按实际增减计入；旧版 PDF 转换按转换前后的正文差值计入。

同时提取文字和可解码的内嵌图片，按页中位置将图片作为独立段落插入正文。支持普通图片、行内图片、重复引用和透明图片，并保留图片的旋转方向；图片保存为本地 PNG，随书本备份和 PDF 导出。扫描页中可提取的图片也会导入，只有图片的文档同样可创建书籍；如需编辑扫描图片中的文字，仍需先进行 OCR。导入预览显示图片数量，图片标记不计入字数。
解析时禁用浏览器 `ImageDecoder`，确保 JPEG 等图片返回可编码的像素数组；GIF 来源图片按 PDF 中的静态画面导入。PDF 导入、编辑和阅读的 renderjs 回调在宿主节点移除后停止，避免返回页面时继续回调已关闭的页面。

不保留 PDF 的固定页版、表格格式、矢量绘图和复杂剪裁；无法解码的图片和模板遮罩会提示，空白页会跳过。为控制移动设备内存，单张导入图片最多 4096 像素长边、约 419 万像素，超过时自动缩小。取消导入或保存失败会清理本次生成的图片。加密文件需先解密，文件上限 80 MB。旧版 PDF 书架记录可在详情页转换，成功保存图文后才移除旧原文件。

- `src/services/pdf-import.js`：图文提取、排版断行恢复、章节整理。
- `src/services/pdf-images.js`：图片对象读取、位置与旋转恢复、PNG 编码。
- `src/services/pdf-image-files.js`：图片持久化和取消/失败清理。
- `src/services/android-pdf-picker.js`：Android 文档选择及临时文件读取。
- `components/PdfImportBridge.vue`：App 视图层离线解析，分块传输文件和显示进度。
- `static/pdfjs/`：随云打包分发的解析器、中文字符映射及许可证；请勿删除。
- `scripts/build-pdf-runtime.mjs`：依赖更新后重建上述资源（`npm run build:pdf-runtime`）。普通云打包不需要运行。
- `fixtures/pdf-import-sample.pdf`：含中文文字层、压缩流和两章正文的测试文档，可用 `node scripts/create-pdf-fixture.mjs` 重新生成。
- `fixtures/pdf-images-sample.pdf`：含文字、跨页复用图片和透明通道的测试文档，由同一脚本生成。
- `fixtures/pdf-jpeg-sample.pdf`、`fixtures/pdf-indexed-sample.pdf`：分别覆盖 JPEG 压缩和 GIF 常见的索引色、透明色编码，由同一脚本生成。
- `npm run test:pdf-import`：验证真实 PDF 图文导入、图片方向/透明度、分块传输、取消清理和本地文件保存。
